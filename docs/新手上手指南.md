# qbot 新手上手指南（零基础版）

假设你**什么都不懂**，跟着一步步做就行。整个过程约 15 分钟。
遇到报错先别慌，翻到最后【常见报错】。

> 命令里，Windows 用 `python`，Mac 用 `python3`。下面同时给出，按你的系统选一行。

---

## 第 0 步：确认你有什么

你说电脑已经装了 **Python** 和 **VS Code**，先确认一下：

1. 打开 VS Code
2. 顶部菜单 `终端 / Terminal` → `新建终端 / New Terminal`
3. 在弹出的终端里输入（选你系统对应那行）：

```bash
python --version      # Windows
python3 --version     # Mac
```

看到类似 `Python 3.11.x` 就 OK（3.9 以上都行）。如果提示"不是内部或外部命令"，
说明 Python 没装好，去 https://www.python.org 重装，安装时**务必勾选 Add to PATH**。

---

## 第 1 步：把代码拿到本地

**方法 A（最简单，不用装 git）**
1. 打开项目的 GitHub 页面
2. 绿色的 `Code` 按钮 → `Download ZIP`
3. 解压到一个你找得到的文件夹，比如 `D:\quant` 或 `~/quant`

**方法 B（会用 git 的话）**
```bash
git clone <你的仓库地址>
```

然后在 VS Code 里：`文件 / File` → `打开文件夹 / Open Folder` → 选中这个项目文件夹。

---

## 第 2 步：安装依赖（只需一次）

在 VS Code 的终端里，确认当前在项目根目录（能看到 `requirements.txt`），运行：

```bash
# Windows
python -m pip install -r requirements.txt

# Mac
python3 -m pip install -r requirements.txt
```

等它跑完（第一次会下载一堆包，几分钟）。看到最后没有红色 `ERROR` 就成功了。

> 想更规范可以先建虚拟环境（可选，不建也能用）：
> ```bash
> python -m venv .venv                 # 建
> .venv\Scripts\activate               # Windows 激活
> source .venv/bin/activate            # Mac 激活
> ```

---

## 第 3 步：跑第一个回测（离线，不用联网）

先用合成数据确认系统能跑：

```bash
# Windows
python run_backtest.py --market synthetic --strategy rsi_reversion

# Mac
python3 run_backtest.py --market synthetic --strategy rsi_reversion
```

终端会打印一张绩效表（年化、最大回撤、夏普、胜率……）。**看到这张表 = 系统装好了。** 🎉

---

## 第 4 步：跑真实标的（需要联网）

```bash
# 比特币（加密日线，年周期数用 365）
python run_backtest.py --market crypto --symbol BTC/USDT --strategy regime_switch --ppy 365

# 贵州茅台（A股）
python run_backtest.py --market ashare --symbol 600519 --strategy rsi_reversion

# 想加 ATR 移动止损，就加 --atr-stop 3.0
python run_backtest.py --market crypto --symbol ETH/USDT --strategy supertrend --ppy 365 --atr-stop 3.0
```

> A股代码就是 6 位数字：茅台 `600519`、平安银行 `000001`、宁德时代 `300750`。
> 加密标的格式是 `币种/USDT`，如 `BTC/USDT`、`ETH/USDT`、`SOL/USDT`。

---

## 第 5 步：打开可视化面板 🖥️

```bash
# Windows
python run_dashboard.py

# Mac
python3 run_dashboard.py
```

看到 `Uvicorn running on http://127.0.0.1:8000` 后，
**按住 Ctrl（Mac 按 Cmd）点那个网址**，或直接在浏览器打开 http://127.0.0.1:8000

面板有两个标签页：

- **回测**：选市场/标的/策略 → 点"运行回测" → 看资金曲线、回撤、绩效指标。
- **实时信号扫描**：填一篮子标的（如 `BTC/USDT, ETH/USDT, SOL/USDT`）→ 选策略 → 点"扫描"
  → 系统告诉你每个标的现在该 🟢买入 / ⚪空仓。
  勾"自动刷新60秒"就能盯盘。**🟡高亮行 = 信号刚变化，重点看。**

> 关闭面板：回到终端按 `Ctrl + C`。

---

## 第 5.5 步（可选）：让它在信号变化时通知你 🔔

**面板里最省事**：切到"实时信号扫描"页，勾上"🔔 信号变化时通知我"和"自动刷新60秒"，
第一次浏览器会问要不要通知权限，点"允许"。之后只要有标的信号变化，就会弹桌面通知 + 响一声。

**人不在电脑前也想收到**（比如上班时）：用盯盘脚本，配合微信推送。
1. 先干跑看看效果（不用配任何东西）：
   ```bash
   python run_watch.py --market crypto --symbols BTC/USDT ETH/USDT --dry-run
   ```
2. 想收微信：去 https://www.pushplus.plus 微信扫码登录，拿到 `token`，
   填进 `.env` 的 `PUSHPLUS_TOKEN=`，然后：
   ```bash
   python run_watch.py --market ashare --symbols 600519 000001 300750 --poll 300
   ```
   之后哪个股票信号一变，你微信就收到提醒。它只在**变化那一刻**推一次，不会刷屏。

## 第 6 步：上实盘前，先过"防自欺"这一关

任何策略/参数，在你投真钱前，**必须**先跑样本外验证：

```bash
python run_optimize.py --market crypto --symbol BTC/USDT --strategy regime_switch --ppy 365
```

看输出最后一行：
- ✅ 绿灯 → 相对稳健，可以进下一步（模拟盘）
- ⚠️ 红字"过拟合"/"样本外为负" → **这套参数别碰**，换标的或换策略

## 第 7 步（可选）：接 OKX 模拟盘，让它自动跑

1. 去 OKX → 交易 → **模拟交易** → 生成**模拟盘** API Key（会给你 key / secret / passphrase）
2. 复制项目里的 `.env.example`，改名为 `.env`，填进去，保持 `OKX_DEMO=1`
3. 先跑一个周期看看：
   ```bash
   python run_live.py --broker okx --market crypto --symbol BTC/USDT --strategy regime_switch --once
   ```
4. 没问题就去掉 `--once`，它会 24 小时循环。**这是模拟盘，不花一分钱。**

> ⚠️ 切真钱：把 `.env` 里 `OKX_DEMO=0`，并在命令后加 `--i-understand-the-risk`。
> 请务必先在模拟盘跑稳几周、看懂 `qbot/risk/manager.py` 的每一道风控，再用**很小**的金额试。

## 常见报错

| 报错 | 原因 & 解决 |
|---|---|
| `ModuleNotFoundError: No module named 'xxx'` | 依赖没装好。重跑第 2 步的 `pip install -r requirements.txt` |
| `python 不是内部或外部命令` | Python 没进 PATH。重装 Python 勾选 Add to PATH；或把命令换成 `py` |
| 回测能跑但拉真实数据失败/超时 | 网络问题或数据源临时抽风。稍后重试；合成市场(`synthetic`)永远能用 |
| A股拉数据报错 | 换个时间重试；确认代码是 6 位数字且真实存在 |
| 面板打不开 | 确认终端显示了 `http://127.0.0.1:8000`；换个浏览器；确认没被防火墙拦 |
| 端口被占用 | 改端口：编辑 `run_dashboard.py` 把 `port=8000` 改成 `8001` |

## 三条保命铁律

1. **先模拟，再小额，永不 all in。** 这套系统默认模拟盘就是这个道理。
2. **回测好看 ≠ 能赚钱。** 上实盘前一定过 `run_optimize.py` 样本外这关。
3. **风控优先于收益。** 先想怎么不亏，再想怎么赚。活得久，才有复利。
