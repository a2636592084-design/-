从零把 qbot 跑起来

别怕，你不用懂任何原理。照着下面 7 步做，点哪里、打什么字、 做完会看到什么，我都写清楚了。全程约 15 分钟，不花一分钱、不碰真钱。

你已具备 ✓ Python 你已具备 ✓ VS Code 需要 · 能上网
1

把代码下载到电脑

做什么：从 GitHub 下载项目压缩包并解压。

  1. 浏览器打开项目地址：
    github.com/a2636592084-design/-
  2. 页面左上有个写着 main 的按钮（分支选择），点它， 在列表里选 claude/quant-trading-system-mcoiwh
  3. 点右侧绿色的 <> Code 按钮 → 菜单里点 Download ZIP
  4. 下载完，在"下载"文件夹里找到这个 zip，右键 → 全部解压缩， 解压到桌面方便找
✅ 你会看到：桌面多出一个文件夹，里面有 run_backtest.py、 requirements.txt、deploy 等文件。
⚠️ 找不到绿色按钮/分支？把这一步的截图或链接发我，我帮你看。
2

用 VS Code 打开这个文件夹

做什么：让 VS Code 进入项目。

  1. 打开 VS Code
  2. 顶部菜单 文件 File → 打开文件夹 Open Folder…
  3. 选中第 1 步解压出来的那个文件夹，点选择文件夹
  4. 如果弹出"是否信任此文件夹作者"，点 是，我信任
✅ 你会看到：VS Code 左侧列表出现一堆文件和文件夹（qbot、deploy、docs…）。
3

打开"终端"（打字的黑框）

做什么：调出可以输命令的终端。

  1. VS Code 顶部菜单点 终端 Terminal → 新建终端 New Terminal
✅ 你会看到：VS Code 下半部分弹出一个框，末尾有个闪烁光标， 大概长这样 PS C:\Users\你\Desktop\...>。以后所有命令都打在这里。
小技巧：命令用下面每个黑框右上角的"复制"按钮复制， 在终端里点一下再按 Ctrl+V 粘贴，然后按 回车。
4

安装依赖（只做这一次）

做什么：把程序需要的工具包装上。复制下面这行，粘贴到终端，按回车。

python -m pip install -r requirements.txt
✅ 你会看到：终端刷一堆下载文字，最后出现类似 Successfully installed …。跑完可能要 1–3 分钟，耐心等。
⚠️ 如果提示 python 不是内部或外部命令：说明 Python 没进 PATH， 把命令里的 python 换成 py 再试；还不行就把报错发我。
5

一键启动！

做什么：复制下面这行到终端，按回车。它会自动打开三个小窗口： 面板、盯盘、模拟交易。

deploy\start_all.bat
✅ 你会看到：屏幕上弹出 3 个黑色小窗口，各自开始滚动文字 （分别是"面板""盯盘推送""模拟交易"）。别关它们，它们就是在替你干活。
⚠️ 想换标的/策略？先跑通再说。以后在 VS Code 左侧双击 deploy/start_all.bat 用记事本打开，改顶部 set SYMBOLS=… 即可。
6

打开你的面板 🖥️

做什么：在浏览器地址栏输入下面这个，按回车。

127.0.0.1:8000
✅ 你会看到：一个深色的"qbot 量化面板"网页，顶部有 回测 和 实时信号扫描 两个标签。成功了！🎉
⚠️ 打不开？确认第 5 步那个"面板"黑窗口还开着、且里面有一行 Uvicorn running on http://127.0.0.1:8000。
7

看它给你的第一批信号

做什么：让系统告诉你现在哪些该买、哪些观望。

  1. 面板上点 实时信号扫描 标签
  2. "市场"选 加密 OKX（或 A股）
  3. 点蓝色 扫描 按钮
✅ 你会看到：一张表，每个标的后面标着 🟢买入 / ⚪空仓。勾上"🔔 信号变化时通知我"和"自动刷新60秒"，信号一变就会弹提醒+响声。
想停止全部：把那 3 个黑窗口挨个关掉就行。

🎉 到这就跑起来了

面板在看盘、盯盘在等信号、模拟交易在虚拟练手——全自动，不花钱。
